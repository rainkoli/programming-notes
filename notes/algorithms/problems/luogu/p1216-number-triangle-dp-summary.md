# P1216 数字三角形最大路径和 DP 总结

## 题目模型

给定数字三角形：

``` text
        7
      3   8
    8   1   0
  2   7   4   4
4   5   2   6   5
```

从顶部到底部，每一步只能走左下或右下。

目标： 求最大路径和。

------------------------------------------------------------------------

# 方法一：二维 DP

## 状态定义

dp\[i\]\[j\]

表示： 从位置 (i,j) 到底部的最大路径和。

## 状态转移

dp\[i\]\[j\] = a\[i\]\[j\] + Math.max(dp\[i+1\]\[j\], dp\[i+1\]\[j+1\])

复杂度：

时间 O(r²)

空间 O(r²)

------------------------------------------------------------------------

# 方法二：二维状态压缩为一维 DP

## 核心思想

二维：

dp\[i\]\[j\]

计算第 i 行时，只需要下一行。

因此只保存一行：

dp\[j\]

## 转移

更新前：

dp\[j\] = 下一行左孩子

dp\[j+1\] = 下一行右孩子

更新：

dp\[j\] = a\[i\]\[j\] + Math.max(dp\[j\], dp\[j+1\])

复杂度：

时间 O(r²)

空间 O(r)

------------------------------------------------------------------------

# 方法三：输入时直接一维 DP（top-down）

## 思路

不保存整个三角形。

dp\[j\]

表示到当前位置的最大路径和。

更新需要保护上一层数据，所以：

for(int j=i;j\>=0;j--)

必须从右向左。

## 转移

左边：

dp\[j\] = dp\[j\] + num

右边：

dp\[j\] = dp\[j-1\] + num

中间：

dp\[j\] = Math.max(dp\[j-1\], dp\[j\]) + num

------------------------------------------------------------------------

# 新增：为什么 top-down 一维 DP 必须从右往左？

状态转移：

dp\[j\] = Math.max(dp\[j\], dp\[j-1\]) + num

其中：

-   dp\[j\] 是上一行正上方
-   dp\[j-1\] 是上一行左上方

计算当前 dp\[j\] 时，需要两个上一行数据。

因此必须保护 dp\[j-1\]。

------------------------------------------------------------------------

## 如果从左往右会发生什么？

假设上一行：

dp = \[11, 8, ?\]

处理下一行：

4 2 1

第一步：

j = 0

执行：

dp\[0\] = dp\[0\] + 4

结果：

dp = \[15, 8, ?\]

此时：

原来的 dp\[0\]=11 已经被覆盖。

------------------------------------------------------------------------

第二步：

j = 1

需要：

Math.max(dp\[1\], dp\[0\])

理论：

Math.max(8,11)

但是实际：

Math.max(8,15)

因为 dp\[0\] 已经变成当前行数据。

所以结果错误。

------------------------------------------------------------------------

## 为什么从右往左可以？

初始：

dp=\[11,8,?\]

先更新右边：

dp=\[11,8,9\]

此时左边：

dp\[0\]、dp\[1\]

仍然保持上一行。

继续计算：

dp\[1\]=Math.max(dp\[1\],dp\[0\])+2

使用：

Math.max(8,11)

正确。

最后才更新 dp\[0\]。

------------------------------------------------------------------------

# 新增：开辟新数组实现左往右

如果不想倒序，可以保存上一行。

使用两个数组：

old：

保存上一行状态

dp：

保存当前行状态

计算：

dp\[j\] = Math.max(old\[j\], old\[j-1\]) + num

注意：

不能写：

Math.max(dp\[j\], dp\[j-1\])

因为 dp 保存的是正在生成的当前行。

------------------------------------------------------------------------

## Java代码

``` java
int[] dp = new int[r];

for(int i = 0; i < r; i++){

    int[] old = dp.clone();

    for(int j = 0; j <= i; j++){

        int num = in.nextInt();

        if(j == 0){
            dp[j] = old[j] + num;
        }
        else if(j == i){
            dp[j] = old[j-1] + num;
        }
        else{
            dp[j] = Math.max(old[j], old[j-1]) + num;
        }
    }
}
```

------------------------------------------------------------------------

# 两种 top-down 一维 DP 对比

  方式     数组数量   遍历方向    原因
  -------- ---------- ----------- ------------------
  单数组   1          右 -\> 左   保护旧状态
  双数组   2          左 -\> 右   旧状态保存在 old

------------------------------------------------------------------------

# 最终理解

一维 DP 压缩的本质：

谁会被后面的状态依赖，谁就必须晚更新。

本题：

dp\[j\] 依赖 dp\[j-1\]

所以：

dp\[j-1\] 必须保持旧值。

因此：

-   一个数组：倒序
-   两个数组：正序
