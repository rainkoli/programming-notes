# 面试算法题：计算 1 到 n 的和，禁止使用 +、递归、循环、if/else

## 1. 题目

题目大意：

> 计算 `1 + 2 + ... + 100` 的和，但不能使用：
>
> - 加法 `+`
> - 递归
> - 循环
> - `if/else`

如果题目只固定要求 `1 ~ 100`，从字面上可以直接输出：

```java
System.out.println(5050);
```

但这属于“钻题目漏洞”。

更有算法意义的版本应该推广为：

> 给定 `n`，求 `1 ~ n` 的和，并且不能使用 `+`、递归、循环、`if/else`。

---

## 2. 正常数学公式

等差数列求和：

\[
1+2+\cdots+n=\frac{n(n+1)}{2}
\]

普通写法：

```java
return n * (n + 1) / 2;
```

问题在于题目禁止使用 `+`。

所以关键变成：

> 如何不使用 `+` 得到 `n + 1`？

---

## 3. 利用位运算得到 n + 1

Java 整数使用二进制补码。

有一个重要恒等式：

\[
\sim n = -n-1
\]

因此：

\[
-\sim n = n+1
\]

所以：

```java
-~n
```

等价于：

```java
n + 1
```

但没有使用 `+` 运算符。

---

## 4. 用 n = 5 模拟

假设：

```text
n = 5
```

低位二进制可以简化表示为：

```text
0000 0101
```

执行按位取反：

```java
~5
```

得到：

```text
1111 1010
```

在补码中表示：

```text
-6
```

因此：

```java
-~5
```

结果就是：

```text
6
```

即：

```text
5 + 1
```

所以可以记住：

```text
-~n  ≡ n + 1
~-n  ≡ n - 1
```

---

## 5. 用右移代替除以 2

公式已经可以改写成：

\[
\frac{n(-\sim n)}{2}
\]

对于这里的非负整数结果，可以使用：

```java
x >> 1
```

代替：

```java
x / 2
```

因此：

```java
(n * (-~n)) >> 1
```

就是：

```java
n * (n + 1) / 2
```

---

## 6. Java 实现

推荐使用 `long`，避免 `n * (n + 1)` 在 `int` 中提前溢出：

```java
public static long sum(int n) {
    return ((long) n * -~(long) n) >> 1;
}
```

完整示例：

```java
public class Main {

    public static long sum(int n) {
        return ((long) n * -~(long) n) >> 1;
    }

    public static void main(String[] args) {
        System.out.println(sum(100));
    }
}
```

输出：

```text
5050
```

---

## 7. n = 100 完整模拟

首先：

```text
n = 100
```

计算：

```java
-~100
```

得到：

```text
101
```

于是：

```text
100 × 101 = 10100
```

再右移一位：

```java
10100 >> 1
```

对于这个正整数，相当于：

```text
10100 / 2
```

得到：

```text
5050
```

因此：

\[
1+2+\cdots+100=5050
\]

---

## 8. 为什么使用 long？

如果写成：

```java
public static int sum(int n) {
    return (n * -~n) >> 1;
}
```

对于 `n = 100` 没有任何问题。

但如果 `n` 很大：

```java
n * (n + 1)
```

可能在除以 2 之前就已经发生 `int` 溢出。

所以更稳妥的写法是：

```java
public static long sum(int n) {
    return ((long) n * -~(long) n) >> 1;
}
```

---

## 9. 这道题真正考什么？

它并不是在考“会不会等差数列求和”，而更可能是在考：

- 二进制补码；
- 按位取反 `~`；
- 一元负号 `-`；
- 移位运算 `>>`；
- 对限制条件的转换能力。

核心转换：

```text
正常公式：

        n(n + 1)
S(n) = ----------
            2

n + 1 → -~n

        n(-~n)
S(n) = --------
           2

/2 → >> 1

S(n) = (n * (-~n)) >> 1
```

---

## 10. 面试回答模板

可以回答：

> 正常公式是 `n(n+1)/2`。题目禁止使用 `+`，而补码中 `~n = -n - 1`，因此 `-~n = n + 1`。再利用右移一位表示正整数除以 2，可以写成 `((long)n * -~(long)n) >> 1`。整个过程没有使用循环、递归、`if/else` 和 `+`。

---

## 11. 核心结论

```java
public static long sum(int n) {
    return ((long) n * -~(long) n) >> 1;
}
```

记忆：

```text
-~n = n + 1
~-n = n - 1
x >> 1 ≈ x / 2（这里针对非负整数）
```

最终：

```text
sum(100) = 5050
```
