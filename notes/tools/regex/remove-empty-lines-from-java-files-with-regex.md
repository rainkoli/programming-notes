# Java 文件删除所有空行：正则表达式总结

## 1. 需求

目标：在一个 `.java` 文件中，一次性删除所有空白行，包括：

- 完全没有字符的空行；
- 只包含空格的空行；
- 只包含 Tab 的空行；
- 同时兼容常见的 LF（Linux/macOS）和 CRLF（Windows）换行。

正常包含 Java 代码、注释或其他字符的行不会被删除。

---

## 2. 推荐正则表达式

### 查找

```regex
(?m)^[ \t]*\r?\n
```

### 替换为

替换内容**留空**即可。

也就是：

```text
查找：(?m)^[ \t]*\r?\n
替换：
```

然后执行“全部替换”。

---

## 3. 正则逐段解释

```regex
(?m)^[ \t]*\r?\n
```

| 部分 | 含义 |
|---|---|
| `(?m)` | 开启多行模式，使 `^` 可以匹配每一行的开头 |
| `^` | 匹配一行的开头 |
| `[ \t]*` | 匹配 0 个或多个空格、Tab |
| `\r?` | 匹配可选的回车符 `\r` |
| `\n` | 匹配换行符 `\n` |

因此，它匹配的是：

> 一整行中只有空格或 Tab，随后直接换行。

由于把这一整段（包括换行符）替换为空字符串，所以这条空白行会被直接删除。

---

## 4. 示例

### 替换前

```java
package com.example.demo;


public class UserService {


    private String name;


    public void test() {
        System.out.println(name);
    }

}
```

其中既有真正的空行，也有只包含空格或 Tab 的行。

### 替换后

```java
package com.example.demo;
public class UserService {
    private String name;
    public void test() {
        System.out.println(name);
    }
}
```

---

## 5. IntelliJ IDEA / Android Studio 中使用

1. 打开目标 `.java` 文件；
2. 按 `Ctrl + R`（macOS 通常为 `Command + R`）打开替换；
3. 开启 **Regex / 正则表达式** 模式；
4. 在查找框输入：

```regex
(?m)^[ \t]*\r?\n
```

5. 替换框保持为空；
6. 点击 **Replace All / 全部替换**。

如果只想处理当前 Java 文件，确认替换范围是当前文件即可。

---

## 6. VS Code 中使用

1. 打开目标 `.java` 文件；
2. 按 `Ctrl + H`；
3. 点击 `.*` 图标，开启正则表达式模式；
4. 查找：

```regex
(?m)^[ \t]*\r?\n
```

5. 替换内容留空；
6. 执行全部替换。

---

## 7. 只删除“完全空”的行

如果只想删除真正什么字符都没有的空行，而**不删除含空格或 Tab 的行**，可以使用：

```regex
(?m)^\r?\n
```

不过实际整理 Java 文件时，通常更推荐：

```regex
(?m)^[ \t]*\r?\n
```

因为很多看起来是空行的行，实际上可能已经包含缩进空格或 Tab。

---

## 8. 为什么不优先写成 `^\s*$`

常见写法：

```regex
^\s*$
```

虽然在部分编辑器中也能使用，但 `\s` 通常不仅包含空格和 Tab，也可能包含换行符。

当目标明确是“删除空白行”时，显式限制为：

```regex
[ \t]
```

更容易控制匹配范围，也更不容易误吞相邻换行。

推荐最终写法仍然是：

```regex
(?m)^[ \t]*\r?\n
```

---

## 9. 如果是在 Java 代码中执行替换

如果不是在 IDE 中手动替换，而是在 Java 字符串中调用 `replaceAll`，需要对反斜杠进行 Java 字符串转义：

```java
String result = content.replaceAll("(?m)^[ \\t]*\\r?\\n", "");
```

这里 Java 字符串里的：

```java
"(?m)^[ \\t]*\\r?\\n"
```

实际传给正则引擎后，相当于：

```regex
(?m)^[ \t]*\r?\n
```

---

## 10. 最终结论

针对“删除一个 `.java` 文件中的所有空白行”这个需求，直接使用：

```regex
(?m)^[ \t]*\r?\n
```

并将替换内容留空。

这是最适合当前需求的版本：既能删除真正的空行，也能删除只含空格或 Tab 的空行，同时兼容常见的 Windows 和 Linux/macOS 文本换行格式。
