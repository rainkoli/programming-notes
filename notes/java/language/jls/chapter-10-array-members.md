# Java Array Members (JLS 10.7) 学习总结

## 1. 数组成员概述

Java 数组类型拥有以下成员：

1.  `public final int length`
2.  `public clone()` 方法
3.  从 `Object` 继承的成员（除了 `clone`）

数组是 JVM 特殊对象类型，不是普通 class，但具备对象特征。

------------------------------------------------------------------------

## 2. length 字段

数组有：

``` java
public final int length;
```

作用：

-   表示数组元素数量
-   创建后不可修改
-   可以为 0

示例：

``` java
int[] arr = new int[5];
System.out.println(arr.length); // 5
```

------------------------------------------------------------------------

## 3. clone() 方法

数组实现了 `Cloneable`。

示例：

``` java
int[] a = {1,2};
int[] b = a.clone();

System.out.println(a == b);
```

输出：

    false

说明：

-   clone 创建新的数组对象
-   元素内容被复制

------------------------------------------------------------------------

## 4. 多维数组 clone 是浅复制

二维数组：

``` java
int[][] a = {
    {1,2},
    null
};

int[][] b = a.clone();
```

结果：

``` java
a == b        // false
a[0] == b[0]  // true
```

原因：

clone 只复制第一层数组。

内部子数组仍然共享。

------------------------------------------------------------------------

## 5. 数组继承 Object

数组拥有 Object 的方法：

-   `toString`
-   `equals`
-   `hashCode`
-   `getClass`
-   `wait`
-   `notify`
-   `notifyAll`

但是数组的 clone 是特殊实现。

------------------------------------------------------------------------

## 6. 核心结论

  特性             结论
  ---------------- -------------------------
  数组是否对象     是
  length           public final 字段
  clone            创建新数组
  一维数组 clone   独立复制
  多维数组 clone   浅复制
  子数组           共享
  父类             Object
  接口             Cloneable、Serializable
